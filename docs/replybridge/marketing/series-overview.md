# Card series guide

Themes and suggested order for Instagram **vertical multi-slide** series **A–F**. Full copy, PNG specs, and filenames follow reply-bridge `marketing/series/` and `CARD_NEWS_STRUCTURE.md`.

---

## Series list

| Series | One-line topic | Example `utm_campaign` |
| --- | --- | --- |
| **A** | Private Reply & Auto DM basics | `auto-dm-basics` |
| **B** | Public **Auto Reply** — thread reply vs DM | `auto-reply-101` |
| **C** | **Automation window**, notifications, reward extension | `automation-window` |
| **D** | **Keywords** & **once per user** tactics | `keyword-rules` |
| **E** | Launch / event playbook | `event-launch-playbook` |
| **F** | **Official API & trust** — account types, expectations | `official-api-trust` |

Each series is usually **10 slides**.

---

## Example 90-day stream

| Window | Order |
| --- | --- |
| Weeks 1–2 | A → B (feature basics) |
| Weeks 3–4 | D → C (tactics → window) |
| Weeks 5–6 | E (use cases) |
| Week 7 | F (trust)—strong before promos |

---

## Production checklist

- Resolution & crop: e.g. **1080×1350** per design rules.
- Proofread and align with reply-bridge `copy.md`.
- Match UTMs to series names for cleaner analytics.

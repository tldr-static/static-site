# Episode 5 — Limited sales & events (without the mess)

**Typical flow:**

1. Post your offer with a **clear keyword** in the caption (e.g. “Comment **SALE**”).  
2. Set **Auto DM** with the link, code, or “how to buy” steps.  
3. Use **once per person** so one user doesn’t farm multiple codes from one post.  
4. Set an **end date** that matches when the sale ends.

**Optional:** Add a **short public reply** for FAQs (“Do you ship to…?”) so the DM stays for the real conversion step.

---

## After the event

- Turn automation off or let the **end date** handle it.  
- Save the post in a Highlight if people still discover it later—but update copy if the offer is over.
